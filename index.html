2025.07 ~ 2025.11 · CTF Platform Backend

MSG_CTF_BACK

GitHub

CTFd를 사용하지 않고 직접 개발한 Spring Boot 기반 CTF 운영 플랫폼 백엔드입니다. Signature 문제 인증 API와 관리자 권한 제한, Redis 분산락 기반 1회성 코드 소비 구조를 구현했습니다.

Role

  • Signature API Controller/Service/Repository 구현
  • 코드 등록, 검증, 중복 처리, 응답 DTO 구성
  • signature API 관리자 권한 정책 적용

Built

  • SHA-256 digest와 PasswordEncoder 기반 검증
  • Redisson RLock으로 동시 제출 race condition 방지
  • 팀별 unlock 기록, consumed flag, consumedAt 관리

Impact

  • 자체 CTF 플랫폼에서 특수 문제 운영 가능
  • 동시 제출 상황에서도 1회성 코드 소비 안정화
  • JWT, IP Ban, 공격 탐지 필터 등 보안 백엔드 경험
Java 17 Spring Boot MySQL Redis Redisson JWT Docker
